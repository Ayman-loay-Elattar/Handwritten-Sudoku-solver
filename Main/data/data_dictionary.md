# Data dictionary

| Field | Source | Meaning |
|---|---|---|
| `pixels` | Real MNIST | 28x28 grayscale image, scaled from 0..255 to 0..1. |
| `label` | Real MNIST | Handwritten digit 0..9; training drops 0 for Sudoku classification. |
| `solution` | Generated | A valid 9x9 grid made by randomized backtracking with a recorded seed. |
| `puzzle` | Generated | Cells removed from `solution` while a CSP uniqueness check remains true. |
| `observed` | Generated | `puzzle` plus a selected number of wrong nonzero digits. |
| `probabilities` | Generated/model output | Class probabilities for 1..9; demo uses a deterministic confidence model when no trained model exists. |
| `correction_log` | Generated | Cell, old digit, replacement digit, and probability cost for each accepted correction. |
| `mosaic` | Generated from real MNIST test images | A 252x252 9x9 image mosaic; each nonzero cell contains a seeded 28x28 test image and blank cells are all-zero. |
| `cell_image` | Real MNIST test image | The 28x28 image used for one Sudoku cell. |
| `blank` | Generated by preprocessing | `detect_blank` marks a cell blank when mean brightness after 0..255-to-0..1 scaling is below 0.05; the NN is not used. |
| `hard_misread` | Generated from real MNIST test images and trained MLP | A test image whose true label is the solution digit but whose MLP argmax is wrong; candidates conflicting with a row, column, or box peer are preferred. |
| `read_digit` / `true_digit` | Model output / generated ground truth | The MLP argmax and the source solution digit recorded for each injected hard misread. |

MNIST is downloaded by `python make_data.py --download --path data/mnist`.
No photographed Sudoku data is claimed: mosaics and hard digits are synthetic.
